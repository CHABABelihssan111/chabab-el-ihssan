ملفات تحسين تحميل الصور — Chabab El Ihssan

استبدل الملفات الثلاثة في نفس المسارات داخل مشروعك:
- src/components/Splash.jsx
- src/components/Footer.jsx
- src/components/BeforeAfter.jsx

ما الذي تغير؟
- أضيفت أبعاد الصور الحقيقية لشعار Splash (220×249) وشعار Footer (631×249).
- أضيفت نسبة أبعاد 4:3 لصور قسم Before/After حتى يحجز المتصفح المساحة مسبقاً. CSS الحالي ما زال يتحكم في العرض والارتفاع وobject-fit، لذلك لا يتغير شكل الصور أو القص أو التصميم.
- لم يتم تعديل الخطوط أو CSS أو Motion أو أي إعدادات للأنيميشن.

JavaScript:
لم أحذف أي JavaScript أو أغيّر Motion. المشروع يستخدم بالفعل lazy loading للصفحات وتقسيم حزم Vite (React / Motion / Leaflet). تحذير Lighthouse عن unused JS لا يثبت وحده أن كوداً بعينه يمكن حذفه بأمان؛ تقليل Motion أو استبدالها قد يغيّر سلوك الأنيميشن، لذلك تركتها كما هي.

الاختبار:
حاولت تثبيت الاعتماديات عبر npm ci مرتين، لكن العملية انتهت بمهلة التنفيذ. لذلك لم أتمكن من تشغيل npm run build أو تأكيد نجاحه في هذه البيئة. شغّل npm ci ثم npm run build محلياً قبل النشر.

ملاحظة: التعديلات محدودة وآمنة بصرياً، لكنها لا تضمن وحدها ارتفاع PageSpeed؛ أعد اختبار Lighthouse بعد النشر.
